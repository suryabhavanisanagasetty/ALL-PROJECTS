# Project 3: Wine Quality Exploratory Data Analysis

## Objective

Explore the factors affecting wine quality using statistical analysis, correlation analysis, data filtering, sorting, and visualization.

## Dataset

Wine Quality Dataset

## Tasks Completed

- Explored the Wine Quality dataset.
- Performed descriptive statistical analysis.
- Calculated the correlation matrix.
- Identified highly correlated features.
- Detected and analyzed outliers.
- Performed filtering and sorting.
- Created data visualizations.
- Recorded observations and conclusions.

## Concepts Covered

- Python
- NumPy
- Pandas
- Statistics
- Correlation
- Data Filtering
- Data Sorting
- Data Visualization
- Exploratory Data Analysis

## Conclusion

The Wine Quality Exploratory Data Analysis project examined the relationships between different physicochemical properties and wine quality. Statistical analysis, correlation analysis, outlier detection, filtering, sorting, and visualization were used to identify important patterns and factors related to wine quality.
