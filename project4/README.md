# Project 4: Diamond Price Analysis

## Objective

Analyze how different features influence diamond prices using data cleaning, statistical analysis, correlation analysis, outlier detection, and visualization.

## Dataset

Diamonds Dataset

## Tasks Completed

- Loaded and explored the Diamonds dataset.
- Checked and handled missing values.
- Checked and removed duplicate records.
- Detected and treated outliers.
- Analyzed categorical and numerical features.
- Calculated statistical measures.
- Analyzed correlations between features.
- Visualized relationships between different features.
- Prepared business insights based on the analysis.

## Concepts Covered

- Python
- NumPy
- Pandas
- Statistics
- Data Cleaning
- Outlier Detection
- Correlation
- Data Visualization
- Exploratory Data Analysis

## Conclusion

The Diamond Price Analysis project explored how different diamond characteristics influence their prices. Data cleaning, statistical analysis, outlier detection, correlation analysis, and visualization were performed to identify important relationships between diamond features and price. The analysis provides useful insights for understanding factors that contribute to diamond pricing.

## Business Insights

- Diamond price is influenced by multiple numerical and categorical features.
- Correlation analysis helps identify features strongly associated with price.
- Outlier detection helps improve the reliability of the analysis.
- Feature relationships can help businesses understand pricing patterns and customer preferences.
