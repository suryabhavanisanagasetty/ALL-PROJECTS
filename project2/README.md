# Project 2: Titanic Data Cleaning & Passenger Analysis

## Objective

Clean the Titanic dataset and analyze passenger survival trends based on age, gender, and passenger class.

## Dataset

Titanic Dataset

## Tasks Completed

- Read the Titanic dataset using Pandas.
- Explored the dataset structure.
- Checked and handled missing values.
- Removed duplicate records.
- Identified and treated outliers.
- Filtered passengers based on age, gender, and class.
- Sorted passenger records.
- Grouped data using groupby().
- Calculated survival statistics.
- Created data visualizations.
- Prepared an EDA report.

## Concepts Covered

- Data Cleaning
- Filtering
- Sorting
- Grouping
- Statistics
- Data Visualization
- Exploratory Data Analysis

## Conclusion

The Titanic Data Cleaning & Passenger Analysis project explored passenger survival patterns based on different demographic and travel-related factors. Data cleaning, filtering, grouping, statistical analysis, and visualization were performed using Python and Pandas to understand the factors associated with passenger survival.
