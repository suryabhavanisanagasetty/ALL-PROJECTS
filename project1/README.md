# Project 1: Student Performance Analysis

## Objective

Analyze student exam performance and identify factors affecting scores.

## Dataset

Student Performance Dataset

## Tasks Completed

- Loaded the dataset using Pandas.
- Performed exploratory data analysis.
- Checked and handled missing values.
- Checked and removed duplicate records.
- Calculated mean, median, mode, variance, and standard deviation.
- Detected and treated outliers.
- Analyzed correlations between variables.
- Created bar chart, line chart, histogram, and scatter plot.
- Prepared an EDA summary with key insights.

## Concepts Covered

- Python
- NumPy
- Pandas
- Statistics
- Correlation
- Data Cleaning
- Exploratory Data Analysis
- Matplotlib

## Conclusion

The Student Performance Analysis project explored student examination data and identified important factors affecting academic performance. Data cleaning, statistical analysis, correlation analysis, outlier treatment, and visualization were performed using Python, Pandas, NumPy, and Matplotlib.
